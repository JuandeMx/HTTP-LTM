4. DIAGNÓSTICO FINAL
========================================================================
El error es: java.net.SocketTimeoutException (timeout de 20 segundos)

Esto significa que la conexión TCP ni siquiera se establece. El servidor
NO rechaza la conexión (eso sería ConnectionRefused), simplemente NO
RESPONDE. Esto indica una de estas causas:

  A) El servicio "maximus-master-web" (Python en puerto 8080) NO ESTÁ
     CORRIENDO en la VPS. Puede haberse caído al reiniciarse o al
     importar el módulo mx_generator.py si falta la librería pycryptodome.

  B) El firewall de la VPS (UFW) está bloqueando el puerto 8080 para
     conexiones entrantes desde internet.

  C) El proveedor del servidor (hosting/VPS) tiene un firewall externo
     que está bloqueando el puerto 8080.

========================================================================
5. COMANDOS DE SOLUCIÓN (ejecutar en la terminal SSH de la VPS)
========================================================================

# Paso 1: Ver si el servicio web está corriendo
systemctl status maximus-master-web

# Paso 2: Si está caído, reiniciarlo
systemctl restart maximus-master-web

# Paso 3: Asegurar que el firewall permita el puerto 8080
ufw allow 8080/tcp
ufw reload

# Paso 4: Verificar que Python está escuchando en el puerto
ss -tlnp | grep 8080

# Paso 5: Si el servicio falla por falta de pycryptodome, instalar
pip3 install pycryptodome --break-system-packages

# Paso 6: Reiniciar de nuevo
systemctl restart maximus-master-web

# Paso 7: Probar localmente en la VPS
curl -s http://127.0.0.1:8080/api/methods
